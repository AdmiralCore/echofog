# Бот для пропусков

Небольшой бот в Telegram, который работает рядом с вашей нодой EchoFog и сам выдаёт людям
**пропуска**: личные ссылки на ноду со сроком и числом устройств. Что такое пропуска, описано в
[docs/operator-api.ru.md](../../../docs/operator-api.ru.md).

Бот умеет две вещи:

- **Раздавать своим.** Вы (админ) пишете боту `/pass аня`, он отвечает ссылкой, вы пересылаете её
  Ане. Бессрочно или на сколько скажете: `/pass аня 30`.
- **Продавать за Telegram Stars**, если задать цену. Человек пишет `/buy`, платит звёздами прямо в
  Telegram, и бот сразу присылает ему ссылку. Заплатил ещё раз — тот же пропуск продлевается, ссылка
  остаётся прежней. Для Stars не нужны ни карта, ни платёжный провайдер, ни ИП: они работают в любом
  боте без настройки.

Бот ходит к ноде через её API внутри сети Docker, наружу никаких портов не открывается.

## Запуск

Нужна нода, уже поднятая по [гайду для VPS](../../../docs/deploy-vps.ru.md), в режиме `isolated`
или `hidden`.

1. **Бот.** В Telegram откройте @BotFather, отправьте `/newbot` и придумайте имя. Он пришлёт токен
   вида `123456:ABC...`.
2. **Ваш ID.** Напишите @userinfobot, он ответит вашим числовым ID. Это админ бота.
3. **Настройки.** Допишите в `deploy/.env`:

   ```bash
   ECHOFOG_ACCESS=isolated
   ECHOFOG_EXIT=true
   ECHOFOG_EXIT_PRICE=0            # платят за пропуск, а не за гигабайты
   ECHOFOG_API_ADDR=0.0.0.0:8090   # API видно только внутри сети Docker
   ECHOFOG_API_TOKEN=<openssl rand -hex 24>

   TG_BOT_TOKEN=<токен от BotFather>
   TG_ADMIN_IDS=<ваш ID>           # несколько через запятую
   TG_STARS_PRICE=0                # 0: только раздавать своим; например 150: продавать
   TG_DAYS=30                      # срок одной покупки
   TG_DEVICES=2                    # сколько устройств на пропуск
   ```

4. **Запуск** (в папке `deploy/`):

   ```bash
   docker compose -f docker-compose.yml -f docker-compose.bot.yml up -d --build
   docker compose -f docker-compose.yml -f docker-compose.bot.yml logs -f bot
   ```

5. Напишите своему боту `/start`.

## Команды

| Команда | Кто | Что делает |
|---|---|---|
| `/pass ИМЯ [ДНЕЙ]` | админ | пропуск для друга; повторно — продлевает |
| `/list` | админ | все пропуска и их состояние |
| `/revoke ID` | админ | отозвать пропуск и отключить его устройства |
| `/refund USER CHARGE` | админ | вернуть звёзды и отозвать пропуск (нужную строку бот присылает при каждой оплате) |
| `/buy` | все | купить `TG_DAYS` дней за `TG_STARS_PRICE` звёзд |
| `/my` | все | свой пропуск и ссылка |
| `/paysupport` | все | вопрос по оплате |

Бот отвечает по-русски тем, у кого Telegram на русском (или украинском, белорусском, казахском), и
по-английски всем остальным. `TG_LANG=ru` или `TG_LANG=en` в `.env` закрепляет один язык для всех.
Тексты лежат в `TEXT` в начале `bot.py`: меняйте их или добавьте свой язык, потом `up -d --build`
ещё раз.

## Что стоит знать

- **Ссылка — это ключ.** Бот отправляет её только тому, кто купил, или вам. При продлении ссылка
  не меняется, поэтому если она утекла: отзовите пропуск (`/revoke ID`), удалите его на сервере
  (`docker compose exec node echofog-node pass delete ID`), и тогда `/pass` или новая покупка
  создадут пропуск с новой ссылкой.
- **Отзыв сам по себе не навсегда.** Следующий `/pass` с тем же именем или следующая покупка этого
  человека продлят тот же пропуск, а продление снимает отзыв. Чтобы закрыть человеку доступ, ещё и
  удалите пропуск на сервере.
- **Звёзды** копятся на балансе бота. Вывести их можно в TON через Fragment, по правилам Telegram и
  с задержкой, которую задаёт Telegram.
- **Возвраты.** Telegram ждёт от платного бота ответа на `/paysupport` и умеет возвращать звёзды.
  Отвечайте людям и при споре делайте `/refund`.
- **Отвечаете вы.** За то, кому и что вы продаёте, отвечает владелец ноды. Правила есть у Telegram,
  у хостера и у законов вашей страны. Прочитайте их до того, как ставить цену.
- **Выход видит, куда ходят люди,** как любой VPN-выход: адреса и имена сайтов. Скажите это
  покупателям.
- EchoFog — экспериментальная программа: аудита не было, против настоящего государственного DPI её
  не проверяли. Скажите и это тем, кто платит.
