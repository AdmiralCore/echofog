# EchoFog

English version: [README.md](README.md)

**VPN, который работает напрямую между людьми и который трудно заблокировать.** Никакой компании
посередине: вы выходите в интернет через компьютеры других людей, а поставить свою ноду и назначить
свою цену может кто угодно. Соединение выглядит как обычный браузер, который открывает обычный
HTTPS-сайт, так что системе DPI у цензора почти не за что зацепиться.

<p align="center"><a href="https://github.com/AdmiralCore/echofog/releases/download/v0.1.0/demo.ru.mp4"><img src="https://github.com/AdmiralCore/echofog/releases/download/v0.1.0/demo.ru.gif" alt="EchoFog: подключение через P2P-выход, зашифрованный чат со звонком в 4K60 и TON-кошелёк" width="960"></a></p>

Бонусом в EchoFog есть бесплатные чаты со сквозным шифрованием и групповые звонки с демонстрацией
экрана до 4K60 — без подписки и без центрального сервера. Трафик оплачивается в TON, без аккаунта и
без комиссии.

> **Статус: экспериментальный.** EchoFog работает от начала до конца в лаборатории и в тестовой сети
> на Docker, но у него **ещё не было** независимого аудита безопасности от специализированной
> организации, и его **ещё не проверяли** против настоящего государственного DPI. Пока не
> полагайтесь на него там, где ошибка может дорого стоить. Сейчас проекту больше всего нужны
> тестирование и отзывы — особенно изнутри сетей с цензурой. Что защищено, а что нет, — в
> [SECURITY.md](SECURITY.md).

## Коротко о том, как это работает

- **Без центрального сервера.** Ноды находят друг друга через DHT. Они соединяются напрямую, если
  позволяют роутеры, пробивают домашние роутеры с помощью сигнальных нод, а если не выходит —
  идут через релей.
- **Трудно заблокировать.** Для цензора соединение с выходом выглядит так, будто Chrome открывает
  настоящий сайт, который стоит рядом с сервером выхода: HTTP/3 поверх QUIC, а если UDP закрыт, то
  HTTPS поверх TCP. Приложение пробует оба пути сразу и оставляет тот, что прошёл. Цензор, который
  сам подключится к ноде без секретного токена, попадёт на этот настоящий сайт. Ещё ноду можно
  спрятать за CDN через WebSocket.
- **VPN.** Локальный SOCKS5-прокси для отдельных программ или весь компьютер через туннель (в
  Windows драйвер Wintun уже встроен). Выходные узлы соревнуются на открытом рынке; приложение
  может само выбрать выход по пингу, цене, скорости и тому, какие ваши сайты через него открываются.
  Выход может быть и скрытым — тогда он обслуживает только тех, кому дал ссылку-приглашение.
- **Сообщения и звонки.** Сквозное шифрование (X3DH + Double Ratchet). Ответы, ветки, правки,
  реакции и закрепы работают в любом чате, и после перерыва чат выглядит одинаково у обоих.
  Группа может быть пространством с текстовыми каналами и голосовыми комнатами, как сервер
  сообщества, только без сервера. Картинки приходят с маленьким превью, их видно до скачивания.
  Звонки и демонстрация экрана идут по деревьям ретрансляции, которые строятся по исходящей
  скорости каждого участника, поэтому трансляция доходит до многих зрителей без центрального сервера.
- **Оплата.** Вы держите TON в своём маленьком контракте-хранилище и подписываете чеки по мере
  использования выхода, а выход раз в несколько часов их собирает. Можно платить и прямым
  переводом TON или USDT.

Подробнее — в [Как это работает](docs/how-it-works.ru.md).

## От чего нода умеет защищаться

| Угроза | Что делает нода |
|---|---|
| DPI узнаёт протокол | QUIC и TLS в форме Chrome с именем настоящего соседнего сайта; первые килобайты каждого туннеля добиваются, чтобы не просвечивало рукопожатие браузера внутри; соединения меняются, чтобы ни одно не жило час и не везло гигабайты ([Anti-DPI](docs/anti-dpi.ru.md)) |
| Цензор прощупывает ноду | без токена зонд попадает на настоящий сайт и видит его сертификат и страницы; обычная нода молчит; повторённое, изменённое или скопированное рукопожатие считается зондом |
| UDP режут или душат | QUIC и TCP набираются одновременно; QUIC, который соединился и замолчал, переводится на TCP; победитель запоминается для каждой сети и переживает перезапуск |
| Наплыв соединений и бесплатные фальшивые ID | лимиты на адрес и подсеть, QUIC Retry и небольшое доказательство работы для незнакомых, баны, которые переживают перезапуск |
| Маленький запрос, на который нода отвечает горой данных | общие для ноды бюджеты на замеры скорости и списки пиров |
| Попытки забить диск или память | квоты и сроки жизни для офлайн-почты, записей DHT и выданных ключей |
| Один пользователь занимает весь релей или выход | лимиты на пира и на адрес; бесплатный выход по умолчанию даёт каждому клиенту до 50 Мбит/с |
| Фальшивые платежи, чтобы нагрузить ноду | неизвестное хранилище проверяется не чаще раза в 10 с на пира |
| Ноду вообще находят | скрытые и изолированные ноды не попадают в DHT и отвечают только по ссылкам-приглашениям ([Скрытые ноды](docs/hidden-nodes.ru.md)) |

Чего одна нода сама остановить не может: поток больше её канала, атакующего с тысячами настоящих
адресов и цензора, который обходит DHT и собирает адреса публичных нод. Трафик между нодами (в
отличие от пути клиент → выход) всё ещё идёт со старой обфускацией, похожей на случайные байты, а
такое правило в духе GFW может отметить. Подробно: [Защита ноды](docs/node-security.ru.md),
[SECURITY.md](SECURITY.md#по-русски).

## Замеры в лаборатории

Тестовая сеть на Docker (`echofog-core-oss/testbed`), три прогона подряд 27 октября 2026 года.
Программа в роли цензора читала трафик на каждой границе, пока три клиента три минуты пользовались
VPN (около 2 ГБ), а браузер для сравнения заходил на изображаемый сайт. Это лаборатория, а не настоящий
государственный DPI.

| Что меряли | Результат |
|---|---|
| Доля байт EchoFog, которую отметили бы правила в духе GFW | 0,0 / 0,0 / 0,1% (25 октября, до маскировки QUIC: 100%) |
| Туннели VPN к выходу, опознанные как обычный HTTP/3 или HTTPS | все; 5 мелких связей mesh к выходу и 15 к другим нодам ещё выглядят шумом |
| Переходы VPN на другой выход за прогон | ни одного |
| HTTPS-заходы через VPN, выданные вложенным рукопожатием | 0 из 24 |
| Первая страница через VPN, когда UDP закрыт на границе | 0,7 с (до гонки QUIC/TCP: 37 с) |
| 300 МБ одним потоком на фоне ротации соединений; 72 закачки разом | целиком; 72 из 72 |
| Один поток через loopback: чистый QUIC / с маскировкой / шум | 40 / 37 / 31 МБ/с |
| Один клиент через бесплатный выход | 50 Мбит/с, лимит выхода на клиента по умолчанию |

Как снимается каждая цифра и чего ещё не хватает: [Anti-DPI](docs/anti-dpi.ru.md#замеры).

## Что лежит в репозитории

Это рабочее пространство Go (`go.work`) из двух модулей:

| Папка | Модуль | Что это |
|---|---|---|
| [`echofog-core-oss/`](echofog-core-oss/) | `github.com/echofog/echofog-core` | нода: транспорт, криптография, обход NAT, DHT, сообщения, звонки, прокси, платежи и серверный бинарник `echofog-node` |
| [`echofog-desktop-oss/`](echofog-desktop-oss/) | `github.com/echofog/echofog-desktop` | приложение для компьютера (Wails: Go + WebView, интерфейс на Svelte); нода работает внутри него |

Десктопный модуль подключает ядро через `replace` на `../echofog-core-oss`, поэтому обе папки должны
лежать рядом.

## Сборка из исходников

Нужен **Go 1.27.3+**. Для приложения ещё нужны **Node 18+** и [Wails CLI](https://wails.io).

Серверная нода:

```bash
cd echofog-core-oss
make build                       # -> bin/echofog-node
./bin/echofog-node init          # создать личность и показать фразу восстановления
./bin/echofog-node run --bootstrap host:port/<peer id>
```

Что значат флаги, какие порты открыть и как запустить в Docker — в [Своя нода](docs/run-a-node.ru.md).

Приложение:

```bash
cd echofog-desktop-oss
wails build                      # -> build/bin/EchoFog(.exe)
wails dev                        # живая перезагрузка с настоящим ядром
```

> Wails CLI v2.11.0 под Go 1.27 нужно собрать со свежим `golang.org/x/tools`, иначе он падает с
> `package "context" without types`. Установите его командой
> `GOTOOLCHAIN=go1.27.3 go install github.com/wailsapp/wails/v2/cmd/wails@v2.11.0` на машине, где в
> кэше модулей уже есть `x/tools` ≥ v0.52.

Тесты:

```bash
cd echofog-core-oss
make test                        # модульные и интеграционные тесты
make test-calls                  # кластер звонков из 10 нод по QUIC
make testbed-chaos               # десять нод за NAT в Docker, с падениями и обрывами
```
