# EchoFog

English version: [README.md](README.md)

**VPN, который работает напрямую между людьми и который трудно заблокировать.** Никакой компании
посередине: вы выходите в интернет через компьютеры других людей, а поставить свою ноду и назначить
свою цену может кто угодно. Соединение выглядит как обычный браузер, который открывает обычный
HTTPS-сайт, так что системе DPI у цензора почти не за что зацепиться.

Бонусом в EchoFog есть бесплатные чаты со сквозным шифрованием и групповые звонки с демонстрацией
экрана до 4K60 — без подписки и без центрального сервера. Трафик оплачивается в TON, без аккаунта и
без комиссии.

> **Статус: экспериментальный.** EchoFog работает от начала до конца в лаборатории и в тестовой сети
> на Docker, но у него **ещё не было** независимого аудита безопасности от специализированной
> организации, и его **ещё не проверяли** против настоящего государственного DPI. Пока не
> полагайтесь на него там, где ошибка может дорого стоить. Сейчас проекту больше всего нужны
> тестирование и отзывы — особенно изнутри сетей с цензурой. Что защищено, а что нет, — в
> [SECURITY.md](SECURITY.md).

## Коротко о том, как это работает

- **Без центрального сервера.** Ноды находят друг друга через DHT. Они соединяются напрямую, если
  позволяют роутеры, пробивают домашние роутеры с помощью сигнальных нод, а если не выходит —
  идут через релей.
- **Трудно заблокировать.** Сначала QUIC, и каждый UDP-пакет замаскирован ключом, привязанным к
  ноде. Если UDP режут, нода переходит на TCP, похожий на HTTPS-сессию настоящего браузера. Цензор,
  который прощупывает ноду без секретного токена, попадает на настоящий сайт, под который она
  маскируется. Ещё ноду можно спрятать за CDN через WebSocket.
- **VPN.** Локальный SOCKS5-прокси для отдельных программ или весь компьютер через туннель (в
  Windows драйвер Wintun уже встроен). Выходные узлы соревнуются на открытом рынке; приложение
  может само выбрать выход по пингу, цене, скорости и тому, какие ваши сайты через него открываются.
- **Сообщения и звонки.** Сквозное шифрование (X3DH + Double Ratchet). Звонки и демонстрация экрана
  идут по деревьям релеев, которые строятся по скорости отдачи каждого участника, — так трансляция
  доходит до многих зрителей без центрального сервера.
- **Оплата.** Вы держите TON в своём маленьком контракте-хранилище и подписываете чеки по мере
  использования выхода, а выход раз в несколько часов их собирает. Можно платить и прямым
  переводом TON или USDT.

Подробнее — в [Как это работает](docs/how-it-works.ru.md).

## Что лежит в репозитории

Это рабочее пространство Go (`go.work`) из двух модулей:

| Папка | Модуль | Что это |
|---|---|---|
| [`echofog-core-oss/`](echofog-core-oss/) | `github.com/echofog/echofog-core` | нода: транспорт, криптография, обход NAT, DHT, сообщения, звонки, прокси, платежи и серверный бинарник `echofog-node` |
| [`echofog-desktop-oss/`](echofog-desktop-oss/) | `github.com/echofog/echofog-desktop` | приложение для компьютера (Wails: Go + WebView, интерфейс на Svelte); нода работает внутри него |

Десктопный модуль подключает ядро через `replace` на `../echofog-core-oss`, поэтому обе папки должны
лежать рядом.

## Сборка из исходников

Нужен **Go 1.27+**. Для приложения ещё нужны **Node 18+** и [Wails CLI](https://wails.io).

Серверная нода:

```bash
cd echofog-core-oss
make build                       # -> bin/echofog-node
./bin/echofog-node init          # создать личность и показать фразу восстановления
./bin/echofog-node run --bootstrap host:port/<peer id>
```

Что значат флаги, какие порты открыть и как запустить в Docker — в [Своя нода](docs/run-a-node.ru.md).

Приложение:

```bash
cd echofog-desktop-oss
wails build                      # -> build/bin/EchoFog(.exe)
wails dev                        # живая перезагрузка с настоящим ядром
```

> Wails CLI v2.11.0 под Go 1.27 нужно собрать со свежим `golang.org/x/tools`, иначе он падает с
> `package "context" without types`. Установите его командой
> `GOTOOLCHAIN=go1.27.2 go install github.com/wailsapp/wails/v2/cmd/wails@v2.11.0` на машине, где в
> кэше модулей уже есть `x/tools` ≥ v0.52.

Тесты:

```bash
cd echofog-core-oss
make test                        # модульные и интеграционные тесты
make test-calls                  # кластер звонков из 10 нод по QUIC
make testbed-chaos               # десять нод за NAT в Docker, с падениями и обрывами
```
