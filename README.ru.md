# EchoFog

English version: [README.md](README.md)

**P2P-мессенджер для сообществ, который работает там, где другие блокируют.** Группы с каналами и
голосовыми комнатами, звонки, трансляции экрана до 4K при 60 кадрах, файлы и доставка тем, кто не в
сети, — без сервера посередине, который можно выключить. Сообщения и звонки зашифрованы сквозным
шифрованием. Там, где сеть фильтруют, соединение выглядит как обычный заход на обычный сайт.

Вторая функция — встроенный VPN: выходите в интернет через выход, который держит знакомый или оператор,
или раздайте свой.

> **Статус: 0.3.0, первый выпуск на протоколе v2. Экспериментальный.** Всё работает от начала до конца в
> нашей лаборатории и тестовых сетях, но **независимого аудита безопасности ещё не было**, и **внутри
> настоящей государственной системы цензуры его ещё не проверяли**. Не полагайтесь на него там, где от
> этого зависит ваша безопасность. Больше всего проекту сейчас нужны проверки и отзывы, особенно изнутри
> фильтруемых сетей. Что защищено, а что нет, — в [SECURITY.md](SECURITY.md#по-русски).

## Что можно делать

- **Сообщества без сервера.** Группа — это пространство с текстовыми каналами, категориями, ветками,
  ролями и правами по каналам, приглашениями со сроком, заявками на вход, медленным режимом и банами.
  История живёт на устройствах участников и подписана авторами.
- **Общаться.** Личные чаты с ответами, ветками, реакциями, правкой, закрепами, упоминаниями и
  сохранёнными сообщениями. Голосовые комнаты, куда входят одним щелчком, звонки один на один и в
  группе, трансляции экрана до 4K60. Трансляция идёт по дереву из каналов самих зрителей, поэтому
  доходит до многих людей без сервера.
- **Файлы и голосовые сообщения.** Любого размера, с докачкой после обрыва, попадают в ту группу, канал
  и ветку, куда их отправили.
- **Доставка тем, кто не в сети.** Сообщение ждёт в зашифрованном почтовом ящике до 7 дней. Приложение
  показывает честные состояния: «ждёт связи», «в почтовом ящике», «доставлено», «срок истёк».
- **VPN, когда он нужен.** Вставьте ссылку на выход — и выходите в интернет через него: как локальный
  SOCKS5-прокси или всем компьютером, с защитой от утечек (Windows и Linux). Свой компьютер можно сделать
  выходом для тех, кого вы выберете.
- **Своя нода.** Одна команда ставит серверную ноду с полноэкранным установщиком: готовые наборы
  настроек, проверка системы, автозапуск, в конце — ссылка и QR-код. Нода может быть релеем, держать
  почтовые ящики, работать выходом и показывать сайт-обложку.

## Коротко о том, как это работает

- **Без центрального сервера.** Ноды находят друг друга через DHT и обмен списками соседей. Соединяются
  напрямую, если позволяют роутеры, пробивают домашние роутеры (в том числе симметричный NAT), а если не
  выходит — идут через другую ноду как через релей. Релей видит только шифротекст.
- **Сквозное шифрование.** Чат начинается с PQXDH — гибрида с постквантовой частью (X25519 и
  ML-KEM-768) — и продолжается двойным храповиком. Каждый участник группы получает сообщения по своей
  сессии. Звонки зашифрованы внутри этих сессий; в 0.3.0 участники звонка, которые пересылают
  трансляцию другим, её видят (подробно — в [SECURITY.md](SECURITY.md#по-русски)).
- **Трудно заблокировать.** Через фильтруемую границу соединение выглядит как браузер, который открывает
  собственный сайт ноды по HTTP/3, а если UDP закрыт — по HTTPS. Цензор, который подключится к ноде без
  секретного токена, увидит этот сайт. Для каждой страны есть политика маршрутов: например, в мобильных
  сетях России приложение идёт через вход внутри страны, а соединение, которое замерзает примерно после
  16 КБ, помечается и обходится. Между пирами, где ничего не фильтрует, трафик — обычный UDP, похожий на
  случайные байты.
- **Ваш адрес.** Скрытые ноды не попадают в DHT и отвечают только по ссылкам-приглашениям. Собственный
  трафик приложения можно пустить через Tor или другой SOCKS5-прокси, а звонки — только через релей.

Подробнее: [Как это работает](docs/how-it-works.ru.md).

## Что мы измерили, а что ещё нет

Цифры из нашей лаборатории, а не от настоящего государственного цензора:

| Замер | Результат |
|---|---|
| Замаскированный QUIC (reality2-quic) против детекторов лаборатории: отпечаток, SNI, SNI против адреса, форма потока | 0 срабатываний |
| Активные зонды ноды (повтор, искажённое рукопожатие, проверка обложки, токен) | 0 ответов, которые выдают ноду |
| Трансляция экрана 1440p60, 1440p144, 2160p60 напрямую и через релей, против протокола v1 | та же частота кадров, 0 % потерь |
| Голос в комнате на 5 человек, задержка p95 | 135 мс (v1: 136 мс) |
| Релей голосовой комнаты отключился без предупреждения | слушатели вернулись за 0,7 с |

Пока не доказано и поэтому не обещано: что маскировка по TCP неотличима от браузера (размеры записей и
тайминги ещё отличаются), что-либо про Китай и Иран и поведение в настоящих мобильных сетях России. Это
следующие задачи для лаборатории и полевых проверок.

## Устройство репозитория

Рабочее пространство Go (`go.work`) из двух модулей:

| Папка | Модуль | Что это |
|---|---|---|
| [`echofog-core-oss/`](echofog-core-oss/) | `github.com/echofog/echofog-core` | нода: транспорт, криптография, обход NAT, DHT, сообщения, звонки, файлы, VPN и серверная программа `echofog-node`. Протокол v2 — в `internal/v2/` |
| [`echofog-desktop-oss/`](echofog-desktop-oss/) | `github.com/echofog/echofog-desktop` | приложение для компьютера (Wails: Go + WebView, интерфейс на Svelte); нода работает внутри него |

Модуль приложения подключает ядро директивой `replace` на `../echofog-core-oss`, поэтому обе папки должны
лежать рядом.

## Сборка из исходников

Нужен **Go 1.27.3+**. Для приложения ещё **Node 18+** и [Wails CLI](https://wails.io).

Серверная нода:

```bash
cd echofog-core-oss
make build                         # -> bin/echofog-node
./bin/echofog-node v2 setup        # полноэкранный установщик; с --yes и флагами работает без вопросов
```

Чтобы поставить выпущенную ноду на сервер, используйте подписанный `install.sh` и сначала проверьте его:
[VPS на протоколе v2](docs/deploy-vps-v2.ru.md).

Приложение:

```bash
cd echofog-desktop-oss
wails build                        # -> build/bin/EchoFog(.exe)
wails dev                          # живая перезагрузка с настоящим ядром
```

> Wails CLI v2.11.0 под Go 1.27 нужно собрать со свежим `golang.org/x/tools` (иначе ошибка
> `package "context" without types`): `GOTOOLCHAIN=go1.27.3 go install
> github.com/wailsapp/wails/v2/cmd/wails@v2.11.0` на машине, где в кэше модулей уже есть `x/tools` ≥ v0.52.

Тесты:

```bash
cd echofog-core-oss
make test                          # модульные и интеграционные тесты
make test-race                     # то же с детектором гонок
make testbed                       # тестовая сеть в Docker
```
